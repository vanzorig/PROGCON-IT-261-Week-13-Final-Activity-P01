# PROGCON IT261 Week 13 Final Activity

## Project Title
Rock, Paper, Scissors Game

## Project Description
The Rock, Paper, Scissors Game is a simple Python game where a player competes against the computer. The player chooses rock, paper, or scissors, and the computer randomly selects its own choice. The program compares both choices and displays the result.

## Objectives
- Practice using functions in programming.
- Apply conditional statements and loops.
- Generate random choices using Python.
- Create a flowchart using Flowgorithm.
- Convert the flowchart into Python code.
- Practice collaboration using GitHub branches and commits.

## Program Logic
1. Start the program.
2. Display the game instructions.
3. Ask the player to choose rock, paper, or scissors.
4. Generate the computer's random choice.
5. Compare the player's choice with the computer's choice.
6. Display both choices and the game result.
7. Ask the player if they want to play again.
8. Repeat the game if the player chooses yes.
9. End the program if the player chooses no.

## Functions
- `main()` – Controls the main program flow.
- `get_player_choice()` – Gets the player's choice.
- `get_computer_choice()` – Generates the computer's choice.
- `determine_winner()` – Determines the game result.
- `play_again()` – Asks whether the player wants to play again.

## Game Rules
- Rock beats scissors.
- Scissors beats paper.
- Paper beats rock.
- If both choices are the same, the result is a draw.
